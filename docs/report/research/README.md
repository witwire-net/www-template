# 調査報告と調査ログ

このディレクトリには、`researcher` が実施した調査の結果と経過を保存します。重複した調査を避け、過去の判断で参照した情報と調査手順を後から確認できるようにすることが目的です。

## 信頼性に関する注意

ここにある文書は、作成時点の証拠を記録した調査報告または調査ログです。継続的に保守される仕様書、設計書、運用手順、一次資料ではありません。

情報は時間の経過とともに劣化します。特に、リポジトリ構造、依存パッケージ、外部サービス、価格、市場、法令、規約、標準、セキュリティ情報は変更される可能性があります。新しい日付の報告であっても、調査範囲の不足、出典の誤読、依頼時の前提との相違があり得ます。

したがって、報告の内容を一概に信用してはいけません。既存報告は調査の手掛かりとして扱い、重要な主張は現在の一次資料とリポジトリの状態に照らして再検証してください。現在の依頼や提供された情報と矛盾する場合は、既存報告を優先してはいけません。

## 保存規則

- 保存先は `YY/MM/DD/<HHMMSS>-<topic-slug>.md` とします。
- 同名の報告を上書きしません。
- 調査日時、調査範囲、既存報告の評価、確認済みの事実、推論、矛盾、不確実性、出典、調査ログを記録します。
- 秘密情報、認証情報、トークン、Cookie、ブラウザ状態、個人情報、不要な機微情報を記録しません。
- 報告書は `.opencode/skills/research-report/assets/report-template.md` に従って作成します。
